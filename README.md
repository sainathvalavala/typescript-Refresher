# Typed Interfaces

**A book-style journey from "Why TypeScript?" to professional TypeScript + React:** 16 parts and 99 chapters. Every subtopic is explained with code examples, and every part has exercises, projects, and checkpoints.

| Folder | What's inside |
|---|---|
| [`website/`](website/README.md) | **The book as a React website.** Each chapter is an MDX file with explanations, examples, and exercises. Includes search, progress tracking, and dark mode. |
| [`curriculum/`](curriculum/README.md) | The curriculum design: vision, learning roadmap, chapter plans, projects, difficulty curve, and the review behind them. |
| `.github/workflows/` | Builds the website and publishes it to GitHub Pages on every push to `main`. |

## Read it

- **Online:** once GitHub Pages is enabled (Settings → Pages → Source: **GitHub Actions**), the book is published at `https://<username>.github.io/<repository>/`.
- **Locally:**

  ```sh
  cd website
  npm install
  npm run dev        # open http://localhost:5173
  ```
